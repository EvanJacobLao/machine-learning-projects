# Iris Classification with kNN

Classifies Iris flowers using a k-Nearest Neighbours classifier
implemented from scratch with NumPy.

## How it works
- Loads and prepares the Iris dataset.
- Splits the data into training and test sets.
- Calculates Euclidean distances.
- Predicts species using majority voting among the nearest neighbours.
- Evaluates predictions using accuracy.

## Run
From the knn-iris folder:

python -m pip install -r requirements.txt
python iris_knn_from_scratch.py
